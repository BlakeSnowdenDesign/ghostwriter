## 5. Voice-first funnel
Discover → voice/text/upload → limited follow-up interview → three distinct treatments → select package → approve story bible → draft/revise → media/adaptation → export/pitch. Free audition 5–10 min capped, anonymous abuse/rate controls; account required for durable private project and paid operations. Three treatments each title, premise/logline, synopsis, tone, audience, opening sample. Fiction imaginative; nonfiction alternative structures cannot invent factual events. Optional paid visual/audio proof of concept. Keep original input, do not discard unselected directions.
Phase 1 recorded turns: MediaRecorder supported codecs, permission prompts, pause/resume/stop, chunked/recoverable upload, explicit recording consent, editable transcripts with raw version retained, timestamp segments, text fallback, spoken playback, reconnect/resume. Phase 2 streaming STT/TTS, turn detection, interruption, optional phone after privacy review. Interview profiles fiction, screenplay, memoir, biography, business, historical nonfiction. Ask meaningful follow-ups, avoid repeated questions. Extract proposed interpretation separately from original statement; customer approval required to canonize.
## 6. Story intelligence and generation
Canonical story universe with versioned snapshots, characters/relationships, events, world, themes, voice profile, research, visual bible, approved decisions. Each adaptation branches from immutable snapshot and documents departures; never accidentally change source manuscript. Retrieve relevant sections, summaries and canonical context instead of whole manuscript on every call. Semantic search must be workspace scoped. Generation: authenticate/authorize → classify intent → retrieve context → quote/reserve credits → select agent/model/prompt version → structured generation → validate and continuity check → present suggestion → accept/reject → version/save. Settle charges according to actual job delivery policy, independent of editorial acceptance, with clear terms; release unused reservation. No agent can charge, publish, send or overwrite canon on its own.
See CREATIVE-ENGINE.md for agent roles, writing method, candidate repositories and model routing. Evaluate multiple treatments independently before critic; one primary authorial voice. Nonfiction use provenance categories and flag contradictions, sensitive allegations and reconstruction; never fabricate sources. Document author contributions without guaranteeing copyright.

## 8. Editors and deliverables
Manuscript: structured rich text, chapter reordering, headings, comments, footnotes/citations, word counts, autosave, version diff, selection-level AI suggestions via voice/text, explicit accept/reject. Screenplay: scene heading, action, character cue, dialogue, parenthetical, transition, title page, optional scene numbering, keyboard shortcuts, scene navigation, character filters, Fountain import/export and validated FDX. Actual rendered pagination not words/pages approximation. Preserve all original revisions. Adaptation proposal describes retained, condensed and changed material; branch only after approval. Exports from fixed revision: DOCX, PDF, EPUB, Fountain, FDX, PPTX, MP4, MP3/WAV, ZIP/JSON archive. Validate DOCX/PPTX/EPUB, screenplay pagination and Final Draft compatibility; record version/hash and appropriate rights/disclosure metadata.
## 9. Hollywood production
Visual bible: approved fictional/authorized character references, wardrobe, age, expressions, locations, lighting, grading, mood, cinematography, continuity and asset rights. Image provider configurable; track source/consent/license. Pitch deck editable 12–20 slides: title/key art, logline, synopsis, genre/tone, world, protagonist, supporting cast, relationships, conflict, structure, themes, visual direction, storyboards, intended audience, comps, creator statement, status/rights, contact. No fabricated production attachments or budget claims. PPTX/PDF exports.
Trailer workflow: treatment → timecoded shot list → low-cost still storyboard approval → cost quote → individual video shots → licensed/original audio and authorized narration → HyperFrames/FFmpeg assembly → frame/audio/duration/continuity QA → MP4, thumbnail, poster, optional social versions. HyperFrames skill: inspect official and registry; check JSON, snapshot contact sheet, fix, render. Validate exact commands/current versions. HyperFrames composes footage, not source video generation. 60s example: 0–5 opening, 5–15 character, 15–30 conflict, 30–45 montage, 45–55 climax/question, 55–60 title. Reuse/replace individual shots; cap retries and budget. No full-film generation MVP.
Pitch room: attractive standalone private microsite, trailer/key art/synopsis/deck/script selected by owner. Expiring scoped grants, optional password, revocation, watermarks, minimal consent-aware analytics; private files signed only after authorization. Noindex not security. No guarantee of Hollywood deal.

## 16. Roadmap and acceptance
Illustrative 17-week plan, not commitment.
1 (weeks 1–2): repo, design system, Wix site and CMS, auth, DB/storage, API, preview, CI. Acceptance real test identity, private project creation, CMS read and deploy check.
2 (3–4): voice upload/transcribe, interview, three treatments. Acceptance dictated original idea yields coherent selectable directions, text fallback, session recovery.
3 (5–8): canon, agents, manuscript/script editors, versions, exports. Acceptance multi-chapter/scenes without canon loss; approved suggestions and validated outputs.
4 (9–10): checkout, entitlements, credits, admin. Acceptance verified test payment exactly once, refund/concurrent spending safe.
5 (11–14): visual bible, adaptations, pitch deck, trailer and private pitch rooms. Acceptance coherent approved cross-media package and revoked grants denied.
6 (15–16): beta, software/security/accessibility tests, blind creative evaluation, measured provider costs, 10–20 paying users. Gate on quality, satisfaction and viable margins.
7 (17+): approved launch, actual content, acquisition, metrics, optimization. Later professional marketplace, live voice, full film only if validated.
